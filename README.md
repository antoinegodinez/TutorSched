# 📚 TutorSched - Mobile Tutoring Scheduling System

An Android application developed as a final project for Individual Laboratory (INTPROG). TutorSched connects Learners, Tutors, and Coordinators to manage academic tutorial sessions, availability, and booking requests seamlessly.

## 🚀 Project Overview & Phases
Following a structured 4-phase development lifecycle:
* **Phase 1: Analysis, Design & Local Prototype** – Screen navigation, data models, and local mock data displayed via RecyclerView.
* **Phase 2: Firebase Foundation** – Firebase Authentication and Cloud Firestore setup for cloud data synchronization.
* **Phase 3: Complete Functional Application** – Full CRUD operations, input validation, and case-specific workflows.
* **Phase 4: Testing, Refinement & Defense** – Bug resolution, functional testing, and final code defense.

## 🛠️ Tech Stack & Architecture
* **Language:** Kotlin
* **UI Components:** Views, RecyclerView, Custom Adapters, XML Layouts.
* **Backend & Database:** Firebase Authentication & Cloud Firestore.
* **IDE:** Android Studio

## 👥 User Roles
* **Learner:** Browse available tutors, check subjects, and book tutorial sessions.
* **Tutor:** Manage availability, view pending requests, and approve/reject sessions.
* **Coordinator:** Oversee platform records and user management.
